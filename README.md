# MGT4017 – Ski Trace website

Static website (HTML, CSS, JavaScript) built from the Ski Trace homepage wireframe.

Open `index.html` in a browser to preview locally.

## Publish with GitHub Pages
1. Upload all files (index.html, css/, js/) to the root of the repository.
2. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. After a minute the site is live at https://YOUR-USERNAME.github.io/MGT4017/
